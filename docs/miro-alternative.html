화이트보드에 통화와 채팅이 붙어 있다면

Walkie는 그룹 음성 통화·채팅·무한 보드를 한 화면에 둔 무료 한국어 앱이에요. 회의 앱과 보드 앱을 따로 켤 필요가 없어요.

Windows 무료 받기 Microsoft Store 안드로이드 APK

이런 분께: Miro 같은 온라인 화이트보드를 무료로, 한국어로 쓰고 싶은 분

Walkie로 할 수 있는 것

  • 통화·채팅·보드가 한 화면 — 링크를 따로 주고받지 않아요
  • 대화와 보드는 서버에 저장하지 않고 멤버 기기끼리 암호화(P2P)
  • 포스트잇·도형·연결선·마인드맵·표·그래프·프레임·템플릿 8종
  • 엑셀 범위를 붙이면 고칠 수 있는 표, PDF는 쪽을 넘겨 보는 카드, 파워포인트로 내보내기
  • Windows 앱(Microsoft Store)과 안드로이드 앱, 한국어·영어·프랑스어

템플릿으로 바로 시작

  1. Walkie를 설치해요(Windows 10·11, 안드로이드). 혼자 쓰는 "이 기기 보드"는 로그인 없이 바로 열려요.
  2. 아래 템플릿 파일(.walkie)을 받아 두 번 누르면 Walkie에서 새 보드 한 장으로 열려요. 앱 안 도구 묶음의 "템플릿"에도 같은 템플릿이 있어요.
  3. 함께 쓰려면 그룹을 만들고 초대 링크를 보내요. 통화를 켜고 같은 보드를 동시에 고쳐요.

Walkie는 이런 점이 달라요

통화·채팅보드와 같은 화면에서 그룹 음성 통화(최대 8명)·채팅
내용 저장 위치대화·보드는 서버에 저장하지 않고 멤버 기기끼리 암호화해 주고받음
설치Windows(Microsoft Store·설치 파일)·안드로이드 앱 — 브라우저판 없음
언어한국어·영어·프랑스어
오피스 연동엑셀 범위 → 고칠 수 있는 표·그래프, 워드·PPT → PDF 카드(PC), 보드 → PPTX 내보내기
요금2026년 12월 31일까지 모든 기능 무료, 이후 요금은 최소 30일 전 고지

Miro는 해당 회사의 상표이며, Walkie는 Miro와 관련이 없어요. 다른 도구의 요금·기능은 각 공식 페이지에서 확인해 주세요.

자주 묻는 질문

브라우저에서도 쓰나요?

아니요. Walkie는 Windows·안드로이드 앱이에요(아이폰은 아직 없어요). 대신 서버에 내용을 두지 않아요.

Miro 보드를 가져올 수 있나요?

보드 파일을 직접 가져오지는 못해요. 이미지·PDF·엑셀 표·글은 붙여 넣을 수 있어요.
