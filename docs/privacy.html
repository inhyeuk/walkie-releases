Walkie 개인정보 처리방침 (베타)

시행일: 2026년 10월 25일 · 베타판 (법률 검토 전 초안 — 정식 서비스 전에 바뀔 수 있어요)

1. 한눈에 보기

  • 대화·음성·보드·파일·위치는 운영자 서버에 저장하지 않아요. 같은 그룹 멤버의 기기끼리 암호화해서 주고받고, 각자 기기에만 저장돼요.
  • 통화는 녹음하지 않아요. 마이크는 통화에 들어간 동안에만 써요.
  • 위치는 직접 시간을 골라 공유를 시작했을 때만, 앱이 열려 있는 동안 그룹 멤버에게 보여요.
  • 로그인은 Google 계정으로 해요. 이메일·전화번호·주소록은 운영자의 서비스 저장소에 두지 않아요.
  • 계정을 삭제하면 운영자 서버의 정보가 지워져요(설정 › 계정 삭제).

2. 처리하는 정보와 목적

정보목적보관
로그인 식별자, 표시 이름(닉네임)계정 구분, 그룹에서 이름 표시계정 삭제 시까지
기기 정보(종류·앱 버전·마지막 접속)기기 구분, 업데이트 필요 여부 안내로그아웃·계정 삭제 시 정리
푸시 토큰호출·새 소식 알림(내용 없음)로그아웃·계정 삭제 시 삭제
그룹 멤버십(그룹 ID·역할·닉네임), 기기 공개키그룹 구성, 암호화 키 전달나가기·내보내기·계정 삭제 시 삭제
연결 협상 메시지, 통화 참가 표시통화·동기화 연결연결 즉시 삭제, 오래된 것은 자동 정리
이용권·이용권 기기, 선택 입력한 이용자 분류(용도·인원·나라·언어), 접속 위치로 짐작한 나라(IP는 저장 안 함)이용권 확인, 서비스 개선이용자가 지우거나 계정 삭제 시

서버에 저장하지 않는 것: 대화 내용, 음성, 보드 그림·사진, 파일, 위치, 이메일·전화번호·주소록.

3. 기기 권한

  • 마이크: 통화에 들어갈 때 묻고, 통화 중에만 사용해요. 원격으로 켜거나 몰래 듣는 기능은 없어요.
  • 알림: 호출·새 소식 알림(내용 없음).
  • 위치: 위치 공유를 시작할 때만, 앱이 열려 있는 동안만 사용해요.

4. 함께 쓰는 외부 서비스

  • Google Firebase(로그인·연결 정보·푸시) — Firestore 서울, Realtime Database 싱가포르
  • Cloudflare Workers(푸시 중계·이용권 확인 — 내용 저장 없음)
  • Metered(직접 연결이 안 될 때 암호화된 통화 중계)
  • GitHub(PC 앱 자동 업데이트·설치 파일 배포) — 업데이트를 확인·내려받을 때 IP 주소가 GitHub에 전달될 수 있어요.

5. 이용자의 권리

  • 계정 삭제: 설정에서 직접 할 수 있어요. 그룹 방장은 다른 멤버가 있으면 먼저 방장을 넘기거나 멤버를 내보내야 해요.
  • 그룹 나가기·멤버 내보내기: 앱에서 직접. 이미 다른 기기에 전달된 내용은 그 기기에 남을 수 있어요.
  • 문의·열람·정정 요청: 아래 문의처로.

6. 안전 조치

대화·보드·파일은 그룹 키로 암호화하고, 모든 변경에 기기 서명을 붙여 위조를 막아요. 전송 구간도 암호화돼요. 키 관리 방식은 정식 서비스 전에 외부 보안 검토를 받을 예정이에요.

7. 아동

만 14세 이상만 이용할 수 있어요.
