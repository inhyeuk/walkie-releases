# Walkie (무료 베타)

- **배포 페이지**: https://inhyeuk.github.io/walkie-releases/
- **내려받기(최신)**: [Windows 설치](https://github.com/inhyeuk/walkie-releases/releases/latest/download/WalkieSetup.exe) · [안드로이드 APK](https://github.com/inhyeuk/walkie-releases/releases/latest/download/Walkie-android.apk) · [사용 설명서 PDF](https://github.com/inhyeuk/walkie-releases/releases/latest/download/Walkie-Guide-ko.pdf)
- 2026년 12월 31일까지 모든 기능 무료 · PC 앱은 자동 업데이트([이용약관](https://inhyeuk.github.io/walkie-releases/terms.html) 제5조)
- 문의·버그 신고: [Issues](https://github.com/inhyeuk/walkie-releases/issues)

이 저장소에는 배포 파일과 배포 페이지만 있어요(앱 소스 코드는 공개하지 않아요). 각 릴리스의 `SHA256SUMS.txt`로 파일을 확인할 수 있고, `latest.json`은 앱이 자동 업데이트에 쓰는 서명된 안내 파일이에요.
